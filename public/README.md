Drop your public branding assets here.

Folders:
- `public/icons/`
- `public/og/`

Files to provide:
- `public/icons/favicon-32.png` - 32x32 PNG favicon
- `public/icons/apple-touch-icon.png` - 180x180 PNG for Apple devices
- `public/icons/icon-192.png` - 192x192 PNG PWA icon
- `public/icons/icon-512.png` - 512x512 PNG PWA icon
- `public/icons/maskable-512.png` - 512x512 PNG maskable icon
- `public/og/app-og.png` - 1280x640 PNG OG image for desktop shares
- `public/og/app-og-mobile.png` - 640x680 PNG OG image for mobile previews

Notes:
- Vite copies everything from `public/` into the built client output automatically.
- `site.webmanifest` is generated by the server at runtime, so you only need to provide the icon and OG image files above.
- App branding text can be changed in `docker-compose.yml` with `APP_NAME` and `APP_DESCRIPTION`.
